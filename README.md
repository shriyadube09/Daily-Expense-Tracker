# Daily Expense Tracker

## About
Daily Expense Tracker is a beginner-friendly Python mini project that helps users manage their daily expenses and monthly budget.

## Features
- Add daily expenses
- View all expenses
- Calculate total expenses
- Search expenses by category
- Check remaining monthly budget

## Technologies Used
- Python 3

## Concepts Used
- Variables
- Lists and Dictionaries
- Functions
- Loops
- Conditional Statements

## How to Run
1. Download the project file.
2. Open it in Python or VS Code.
3. Run daily_expense_tracker.py.

## Conclusion
This project helps users understand basic expense management using Python.
